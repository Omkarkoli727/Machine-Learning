## Projects Included

### 1. IMDb Video Games Analysis

**Notebook:** `imdb-videogames.ipynb`

This project analyzes IMDb ratings and metadata for video games.

**Tasks Performed:**

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Visualization of ratings and trends

**Dataset:** `datasets/imdb-videogames.csv`

---

### 2. California Housing Price Prediction

**Notebook:** `California_Housing_Prices.ipynb`

This project predicts California housing prices using regression models.

**Tasks Performed:**

* Data preprocessing
* Feature engineering
* Model training with Scikit-learn
* Performance evaluation

**Dataset:** `datasets/Callifornia housing.csv`

---

### 3. Heart Disease Prediction

**Notebook:** `heart_model.ipynb`

This project predicts whether a patient is at risk of heart disease.

**Tasks Performed:**

* Data cleaning and preprocessing
* Model training and evaluation
* Interactive prediction interface using Gradio

**Dataset:** `datasets/heart.csv`

---

### 4. Global Life Expectancy Analysis

**Notebook:** `Global Life Expectancy.ipynb`

This project explores factors affecting life expectancy across countries.

**Tasks Performed:**

* Data cleaning
* EDA and visualization
* Correlation analysis

**Dataset:** `datasets/Life Expectancy Data.csv`

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/machine-learning-projects.git
cd machine-learning-projects
```

2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

---

## Running the Projects

Open any notebook and run all cells.

For the Heart Disease project, run the notebook completely to launch the Gradio interface.
